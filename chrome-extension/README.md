# 墨脈 Chrome 研究連接器

在一般 Google Chrome 的 `chrome://extensions` 開啟開發人員模式，按「載入未封裝項目」，選擇本資料夾。

1. 在 Chrome 開啟墨脈 `http://127.0.0.1:4317/#web`，貼文章網址，點擴充功能「連接目前的墨脈分頁」。
2. 在面板授權指定文章網站與 Google 搜尋。
3. 自行登入 Google Notebook，開啟目標筆記本，點擴充功能「連接目前這本 Notebook」。
4. 回墨脈搜尋、勾選、轉 Markdown，讀取已連接筆記本並上傳。

保持墨脈與 Notebook 分頁開啟。重新整理 Notebook、重啟 Chrome 或墨脈後，請重新連接。查看 [完整操作說明](../docs/WEB-RESEARCH.md)。

本機自行載入版本，未發布至 Chrome Web Store。原始碼使用墨脈的 AGPL-3.0-or-later 授權。
