# 墨脈：一般 Google Chrome 研究工作流

## 安裝 Chrome 擴充功能

1. 使用你平常的 Google Chrome，在網址列輸入 `chrome://extensions`。
2. 開啟右上方「開發人員模式」。
3. 點「載入未封裝項目」，選擇 `D:\全球展會\inkgraph\chrome-extension`。
4. 在 Chrome 工具列的拼圖選單，將「墨脈 InkGraph 研究連接器」固定。

這是本機開發的擴充功能，尚未發布至 Chrome Web Store。請核對載入資料夾；程式碼全部在該資料夾內。首次安裝與權限選擇需由你在一般 Chrome 完成。

## 首次連接

1. 在一般 Chrome 開啟 `http://127.0.0.1:4317/#web`，貼上文章網址。
2. 點工具列的墨脈擴充功能，再按「1．連接目前的墨脈分頁」。
3. 面板會帶入文章網址。按「2．允許這個網站與 Google 搜尋」，在 Chrome 權限提示核對網站並選擇是否允許。
4. 在同一個一般 Chrome 手動登入 Google Notebook，開啟要使用的筆記本。
5. 在筆記本分頁點擴充功能，再按「3．連接目前這本 Notebook」。可對不同筆記本分頁重複這步。
6. 回墨脈按「讀取已連接筆記本」，選擇目標。

Google 登入由你在一般 Chrome 完成。墨脈不會啟動 Playwright 工作瀏覽器登入 Google，也不讀取或複製 Google Cookie、密碼或驗證碼。

## 每次研究

1. 選擇墨脈專案；未選專案的文章會進待整理收件匣。
2. 貼上文章網址，保留「優先使用一般 Google Chrome 擷取與 Google 搜尋」勾選。
3. 按「搜尋同站文章」。Chrome 連接器會開啟授權網站與 Google 搜尋，讀取可見頁面後關閉成功處理的暫存分頁。
4. 選擇起始文章與最多 10 篇同站相關文章，一批最多 11 篇，再按「擷取勾選文章並儲存 Markdown」。搜尋結果不足 10 篇時保留實際篇數。
5. 在本機閱讀核對，或從「下載／歷史」下載 `.md`。
6. 選擇已連接筆記本與本機文章，按「上傳勾選文章／替換舊版」。
7. 確認操作說明後，連接器在指定 Notebook 的頁面上傳，回寫逐篇結果。

保持一般 Chrome 的墨脈與 Notebook 分頁開啟。背景分頁可能受到 Chrome 節能機制節流，較慢時可切回這兩個分頁。遇到文章登入／驗證或載入失敗，會保留該文章分頁並提示原因，由你處理後重試，不會繞過 CAPTCHA 或付費限制。

## 權限與連線

- 必要權限：`activeTab`、`scripting`、`storage`、`alarms`，以及本機 `http://127.0.0.1:4317/*`。
- Notebook 只在你點擊連接時取得目前分頁的臨時存取權；重新整理或導航後可能需要重新連接。
- 可選網站權限：你指定的文章網站與 `https://www.google.com/*`。manifest 宣告可選 `https://*/*`，安裝時不會自動授予全部網站，每次要求的都是具體網站。
- 可在 Chrome 擴充功能設定移除網站權限。面板「中斷墨脈連線」會清除配對與筆記本登記，網站權限仍由 Chrome 管理。
- 配對憑證只放在 Chrome session storage；重啟 Chrome 或墨脈服務後，請重新連接。
- 本機僅允許帶有效憑證的連接器領取佇列或回報；擴充功能憑證不能讀取墨脈一般資料 API。

## 搜尋與轉檔

- 優先透過一般 Google Chrome 在 Google 搜尋 `site:網站 主題`，搜尋內容為網站與文章標題／你填入的研究主題。
- 以標題與網址的關鍵詞交集排序，最多 10 篇。主機名稱的 `www` 對應視為同站，不擴大至其他子網域。這是候選篩選，不是 AI 語意評分，英文主題較合適。
- Google 搜尋不可用時顯示提示，仍用起始文章同站連結，不會自動改用 Bing。取消 Chrome 選項是手動 HTTPS 備用擷取，此時只從起始頁連結篩選。
- 正文以 Mozilla Readability 與 Turndown 轉 Markdown，不需要 Python、Crawl4AI 或 LLM API Key。
- 保留標題、可取得的作者／日期、網址與擷取時間；圖片圖表需人工核對。過短正文或明顯驗證頁會拒絕儲存。

## 歷史與雲端更新

- 每次擷取保存不可變的 Markdown 附件，正文相同也保留當次時間。
- 去除常見追蹤參數的網址辨識同一來源，沿用文獻 ID 與筆記關聯。正文變更會清除相關摘錄的人工核對標記。
- 歷史附件、同步對照在 `data/inkgraph.sqlite`，完整 ZIP 備份會包含這些資料。
- 雲端檔名為 `InkGraph-來源ID--正文雜湊.md`。同版檔名已出現時不重傳。
- 更新採「新版出現在來源清單後，再嘗試移除墨脈管理的對應舊版」。這不是保留同一雲端來源 ID 的原地修改，舊引用可能失效。
- 找不到精確的舊來源選單會保留舊版，記為「舊版待清理」。不會清除其他手動匯入來源。
- 失敗、跳過或逾時不會記成成功。可用「查看上次上傳結果」繼續查詢；服務重啟會清空未完成佇列。
- 「來源已出現」只代表清單可見，請在 Notebook 開啟來源確認可讀與索引完成。
- 這是本機文章向 Notebook 的單向同步，不會下載 Google 中的新筆記。

## 驗證與限制

`pnpm run check` 檢查應用與連接器語法；`pnpm test` 包含配對／失效、佇列逾時、報告驗證、來源保存及既有功能。內容腳本在 DOM 測試頁執行，背景工作程式以模擬 Chrome API 測試 Google 搜尋與網站授權拒絕。

以上不代表真實 Google Notebook 已驗收。安裝、登入、選本、真實檔案上傳與舊版移除需在使用者的一般 Chrome 驗證；Google 介面變更可能讓操作失敗，請查看逐篇訊息。
