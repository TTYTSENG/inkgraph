# 字彙改列與三軸分類

## 將錯放的筆記改成字彙

1. 開啟筆記，先儲存尚未保存的內容。
2. 點上方「改列資料類型」，確認目標為字彙詞條。
3. 核對詞名、原語／別名，填寫自己的簡明釋義與辨義提醒。完整原文不會因這些欄位留空而刪除。
4. 選擇分類，展開「核對完整正文」，確認影響範圍後執行。

「直接改列」沿用原項目 ID，保留專案共用、全部來源、正文引用、摘錄快照與原始匯入識別；舊的筆記連結會轉到詞條頁。

若有支持／反駁關係指向該筆記，預覽會列出衝突並阻擋直接改列。此時可選「保留原筆記，另建相連詞條」：原筆記及論證保留，另外產生詞條與「衍生自」連結。一般筆記也可主動選用此方式。

詞條可反向改列為一般筆記。詞彙欄位仍保留，原本已有完整說明時不重寫其內容；原先沒有正文時會以詞條欄位組成筆記正文。

## 建立三軸分類

到「字彙辭典 → 管理分類 → 新增分類」。分類軸固定為：

- 學科，例如人文 → 哲學 → 政治哲學。
- 思想脈絡，例如思想傳統 → 作者／流派。
- 應用領域，例如文本研究 → 文本詮釋。

上述只是可自行調整的示例；系統不會替現有研究內容自動指派分類。

同一軸內，每個分類有一個父分類；詞條可以同時指派多個分類。分類全庫共用，詞條仍依目前專案顯示。同一軸多選表示符合任一分類，不同軸之間表示同時符合。可切換「包含子分類」，或只看未分類詞條。

分類旁的數字是目前專案中，包含子分類的去重詞條數。分類搜尋只比對詞名與原語／別名，查全文請使用上方的全文搜尋。

管理分類支援改名及選擇父分類來移動。系統會阻擋循環、跨軸父分類與同層同名分類。刪除時先預覽受影響項目，可移除指派或移往同軸替代分類；子分類移至替代分類之下，未指定替代時移回原父層。刪除分類不會刪除詞條。

## 編寫、引用與核對

詞條包含簡明釋義、完整說明、辨義提醒、例句、多個來源、分類及整理狀態。原文引句與自己的解釋應分開標示；不同作者的同名詞條不會自動合併。

完整說明沿用寫作編輯區：可插入 APA 文內引用、加入摘錄快照、連結研究項目，使用 Ctrl＋S 儲存、Ctrl＋Shift＋L 插入物件連結。編輯區下方保留快捷鍵與語法提示。Mac 可用 Command 取代 Ctrl。

點「編輯資料」調整釋義、來源及分類；來源選項可搜尋並複選。各段引文的位置保留於正文引用或摘錄定位中。整理狀態由使用者選擇，不等於系統已替內容查證。

## 改列歷程與撤回

點項目上方「改列歷程」。直接改列後，若內容及相關連結未再變更，可撤回這次改列；系統會再次檢查版本與關係。

後續已有編輯或連結變動時，不會用舊快照覆蓋新工作，請使用改列預覽重新整理。另建詞條的操作不提供一鍵撤回，以免刪除後續使用的新項目；必要時使用既有刪除預覽。刪除項目時會同時移除其改列歷程。完整備份會保留改列前內容，應視為含研究資料的檔案。

## Light 匯入

未指定用途的筆記，預設為一般筆記／待整理。匯入預覽可逐筆選擇一般筆記、研究問題、寫作草稿、決策紀錄或字彙詞條。成果包的 notes 項目也可明確宣告 kind 為 term，並提供 aliases、definition、scopeNote、example；原有 content 仍完整保留。

同一成果重匯時，保留既有項目的手動改列、分類、釋義與內容，預覽會顯示沿用提示，不覆寫。若原始標題或正文實質更改，現有內容識別可能視為新項目；跨版本的改稿合併尚未支援。預覽的類型選擇只保留於當次頁面操作；排除選擇沿用既有保存機制。

## 輸出與備份

- Markdown／HTML／列印 PDF：包含完整說明、分類路徑、來源、辨義提醒、展開的引用與摘錄。
- 辭典 CSV：包含基本欄位、完整說明、多個來源 ID、分類 ID 與整理狀態；多值 ID 以 JSON 陣列表示。
- 分類對照 CSV：每個「詞條—分類」組合一列，附分類軸與完整路徑。
- JSON：保留項目與分類身份、欄位和關係；專案／單項輸出包含所需分類祖先及來源，不帶出其他專案筆記全文。
- 完整 ZIP：第 4 版，包含所有分類、詞條、改列歷程、引用快照及附件。可讀取第 1～3 版備份；資料衝突仍會停止合併還原。

部分項目 JSON 輸出不等於完整備份；若需要保留完整改列歷程與復原能力，請下載完整 ZIP。APA 清單仍依原始文獻產生，不把自己的詞彙釋義當成外部文獻。

## 目前界線

本輪不包含整庫 AI 分類、批量改列／分類、分類合併、多作者釋義卡比較。分類在每軸內先採單一父層。已編輯後的一鍵差異合併復原尚未提供，系統會阻擋覆寫。

詞條清單按需載入完整說明與摘錄，只先帶必要的關聯索引。未新增本機模型或背景 AI 呼叫。
