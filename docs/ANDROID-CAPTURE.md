# Android 隨手記測試版

手機負責快速記錄，電腦負責整理及辨識。手機不需要雲端帳號，也沒有網路權限。此版使用獨立測試研究庫；不是正式資料庫升級程序。

## 日常操作

1. 開啟「墨脈隨手記（測試）」，點「新增筆記」。輸入想法，按需要拍照、選取照片或錄音。首次麥克風與定位權限由使用者決定，拒絕定位仍可記錄。
2. 首頁直接列出每則記錄，點整列即可進入草稿編輯；「全部／草稿／可傳輸／已接收」是篩選。輸入內容自動保存，上方顯示保存狀態。錄音完成先「停止並保存」，再點固定在下方的「完成記錄」。
3. 以 USB 連接電腦，開啟桌面側欄「手機收件與整理」，先偵測手機，再「接收手機記錄」。直接匯入 `.igc` 的備援入口在「從檔案匯入／環境資訊」。
4. 桌面驗證附件後建立隨記及來源，將照片和錄音加入辨識佇列。辨識結果未經人工校對；原文、自己的輸入與辨識文字分開保留。可暫停、重試、取消或重新辨識。
5. 手機收到簽章回執後顯示「此版本已接收」。首次需確認研究庫身分。這表示電腦已保存，**不代表辨識完成**；辨識進度請看電腦。已完成記錄的「編輯記錄」會保留已傳版本，另建新版草稿。

目前手機版本為 0.2.0-test。首頁提供直接記錄清單及兩列分類，只有一個主要「新增筆記」入口。編輯下方固定「錄音／照片／完成記錄」，錄音中另有持續狀態列。傳輸失敗不會自動刪除手機資料；重傳相同版本不會重複建立筆記。同一記錄的新版本另外保存，不覆蓋電腦端已修改的內容。

刪除：打開一則記錄，點右上「更多」→「刪除此記錄」，檢視附件數與接收狀態，再「確認刪除」。可先選「取消」保留。確認後永久刪除手機該記錄、所屬附件與本 App 產生的所有對應版本傳輸包；電腦已匯入的內容仍保留。錄音或準備傳輸包時不能刪除。手動複製到其他位置的傳輸包不會代為刪除；本批尚未加入回收桶。

桌面將「接收」「辨識」「人工校對」分開顯示；部分附件失敗時可獨立重試，不重傳整則。機器已產生文字不等於已校對。本批尚未提供校對稿或人工完成標記，因此不會自動宣稱研究整理完成。

USB 自動匯入需 Android SDK platform-tools、開發者 USB 偵錯授權。只讀取本 App 在 Download/InkGraph-Capture 的輸出，不掃描相簿或其他 App。亦可透過檔案傳輸複製 `.igc` 後手動匯入。

## 時間、地點與原始附件

保留記錄識別碼、版本、建立／修改時間、時區，以及附件拍攝／錄製時間。定位是建立記錄時的一次取樣，保存量測時間、精確度及取得狀態；拒絕、逾時或定位關閉均保留狀態，不捏造座標。後續附件沿用該記錄位置，並非每次拍攝重新定位。

錄音為單聲道 16 kHz PCM WAV，每段約 60 秒，保留段落順序及偏移時間。原始照片及錄音以內容雜湊命名，存在桌面研究庫的 `originals/`；SQLite 保存索引與關係。辨識不改寫原始檔，圖片方向校正只用於衍生辨識檔。

此版支援 JPEG、PNG、WebP 及 App 錄製的 WAV。每則最多 50 個附件，單檔最多 25 MB，傳輸包最多 200 MB；原圖辨識最多 2,000 萬畫素。超過限制會回報，不靜默略過。

## 本地辨識及負荷

CPU 執行，每次一個工作、最多四個運算執行緒，預設 Whisper base INT8；可改用 small。模型先下載，辨識工作禁止 Python 網路連線。電腦不需升級顯卡驅動。工作有逾時與記憶體保護；這些不是整台電腦的硬性資源配額。

2026-10-25 在 Ryzen 7 4800H、16 GB RAM 的測試：

| 測試 | 處理時間 | 辨識程序峰值記憶體 |
| --- | --- | --- |
| base，60 秒音訊 | 16.6 秒 | 約 394 MiB |
| base，600 秒音訊 | 143.9 秒 | 約 441 MiB |
| small，60 秒音訊 | 47.4 秒 | 約 971 MiB |
| 五種合成圖片，含旋轉、模糊及空白 | 每張約 1.7～2.1 秒 | 約 217～320 MiB |

長音訊由授權短樣本重複組成，只評估負荷，不能據此推論十分鐘自然談話的正確率。專有名詞、台語、環境噪音與照片品質仍需實際校對。實機已匯入一則文字加錄音記錄；真實照片辨識品質尚待使用者驗收。

## 輸出與備份

- 記錄可匯出 Markdown／JSON，辨識結果可下載 TXT／JSON；語音另有 SRT／VTT。原始附件可各自下載。
- 手機分享匯出預設排除結構化地點，不修改研究庫。使用者自己寫在內文的地名不會自動刪除。
- 照片原檔可能包含 EXIF 位置。此版沒有產生移除 EXIF 的照片分享副本；分享原圖前需自行檢查。
- 桌面完整 ZIP 備份使用 v5，包含原始檔、時間地點、傳輸記錄、辨識結果及研究庫回執身分。備份含私人資料，應保存在受保護位置。可還原舊版 v1～v4 備份；v5 不應交給尚未升級的舊程式。
- 刪除項目後，未被引用的實體原始檔目前仍保留在 originals；沒有自動清理或手機自動刪除。

## 開發與重現

桌面需要 Node.js 24.15+；安裝 package.json 相依套件。辨識環境需要 Python 3.12，依 `workers/requirements.txt` 安裝。執行 `workers/media_worker.py --help` 查看模型準備與工作參數；模型先以 `--prepare --models <目錄> --model base` 準備，small 需另外準備。模型不隨程式庫發布。

桌面環境設定：`INKGRAPH_MEDIA_PYTHON` 指向辨識 Python，`INKGRAPH_MEDIA_MODELS` 指向模型目錄，`INKGRAPH_ADB` 指向 adb。測試時使用獨立 `INKGRAPH_DATA_DIR`、`PORT=4318` 及 `INKGRAPH_DISPOSABLE=1`。隨附 `scripts/start-mobile-test.ps1` 對應 repo 與其同層 tools、models、vault 目錄；需先備妥這些環境，勿直接對正式研究庫執行。

Android 原始碼位於 `mobile/android/`，使用 JDK 17、Android SDK 36 與隨附 Gradle wrapper，執行 assembleDebug。安裝同一測試套件的更新可保留資料；不需解除安裝。APK 為開發測試簽章，尚非正式發布版本。

驗證入口：`tests/mobile-capture.test.mjs`、`tests/mobile-capture.browser.mjs`、`tests/android-device.mjs`。裝置測試預設只檢查本 App 畫面，`--draft` 另會建立合成草稿；手機鎖定時停止，不繞過解鎖。完整 Node 測試共 140 項通過；匯入、重傳、版本衝突、損毀附件回復、舊備份相容及大於 250 MiB 備份均有測試。

## 目前邊界

尚未完整測試所有來電、低電量、強制關機與長時間鎖屏組合；錄音中斷時盡力回復已寫入片段，不能保證突發斷電零損失。沒有 Wi-Fi／雲端同步，也不自動刪除手機原始記錄。正式研究庫切換須另外安排備份、還原演練與驗收。
