# 後續規劃

第一版優先完成可用的本地研究路徑。以下功能尚未實作，不應視為現在已提供。

## 下一版：原文定位與資料整理

- PDF 視覺高亮與摘錄回跳，分開顯示檔案頁序／印刷頁碼。
- OCR 本地處理，保留圖片區域、原始辨識字與人工修訂。
- 筆記自動草稿恢復、垃圾桶與版本歷程。
- 來源重複版本比較、跨專案移動的相依資料一致性。
- DOI 查詢與 RIS/CSL-JSON 書目匯入，預覽後才接受欄位更新。

## 再下一版：寫作與對話來源

- 專用 Gemini Takeout 解析，保留對話角色、時間和附件關係。
- NotebookLM 匯出引用與本地來源的人工配對工作區。
- 可編輯 DOCX 報告、BibTeX 匯出、機構特定中文 APA 樣式。
- Markdown 預覽與摘錄拖入章節，插入後仍可回到來源。

## 研究輔助

- 研究問題的支持／反面證據表。
- 中文索引、搜尋定位、選擇性本地 embeddings。
- 可選本地 AI provider；與雲端模式具有相同的傳送範圍預覽。
- 可插拔來源匯入與輸出介面。

自動雲端同步須先確認官方介面、帳號權限與版本差異處理；不依賴抓取私人帳號網頁作為核心架構。
