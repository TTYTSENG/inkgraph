# 第一階段：閱讀、筆記與可追溯摘錄

完成日期：2026-10-23（Asia/Taipei）。本文件記錄第一階段已完成的程式，不代表第二階段的討論／概念模型已完成。

## 使用方式

1. 開啟一份來源，按「並排筆記」，選擇既有筆記或建立新筆記。
2. 在右側「關聯與出處」找到摘錄，按「加入筆記」。也可從「摘錄與加註」清單進行。
3. 筆記內容會插入摘錄標記；下方「引用摘錄預覽」顯示當時的原文、釋義、加註與來源位置。可在標記前後撰寫自己的判斷。
4. 按「儲存筆記」。從來源側欄可以看到使用此來源的筆記；筆記側欄則區分本篇引用的摘錄與共用來源的其他筆記。
5. 「查看摘錄出處」會開啟來源並標示對應摘錄，不會捨棄仍在編輯的筆記。
6. 匯出 Markdown／HTML 時，摘錄標記展開成完整原文、釋義、定位、引用與識別資訊。完整 ZIP 保存快照與原始附件。

來源與筆記並排時使用相同筆記編輯區。大螢幕右側顯示關聯欄，較窄視窗會把關聯欄移到下方，再窄時改為上下排列。「顯示跨專案關聯」預設關閉；全庫模式則顯示全部專案。跨專案引用保留原檔與識別碼，不複製附件。

## 版本與資料保護

- 摘錄引用保存加入當下的固定快照。修改原摘錄後，筆記提示「摘錄已更新，引用保留舊版」，不自動改寫舊引文。
- 若要採用新版，可再次加入新版摘錄，再移除舊標記並儲存。移除標記會在儲存時移除該次引用。
- 已刪除的來源或摘錄仍能以引用快照閱讀；畫面與匯出會標示來源已移除，不能將快照視為重新核對原檔。
- 來源改名不影響引用。新快照儲存時會與伺服器的實際摘錄核對；舊快照不能在筆記中直接改造為另一段原文。
- 筆記需手動儲存；導覽離開或關閉並排會提示未儲存修改。另一頁籤更新同筆記時，版本衝突會拒絕覆寫，保留本頁草稿。
- 原有來源 ID、筆記 ID、附件與跨專案來源功能沿用；沒有重建正式資料庫或重新編號。新引用為筆記的選填欄位，舊筆記不需批次改寫。
- 檔案頁序與印刷頁碼不同；不把「檔案第 N 頁」自動當成 APA 的印刷頁碼。
