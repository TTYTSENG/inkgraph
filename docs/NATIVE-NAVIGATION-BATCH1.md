# 第一批內建操作：寫作連結、預覽、快速切換

完成日期：2026-10-23。本機服務已啟用：`http://127.0.0.1:4317`。先保存現有編輯，再以 Ctrl＋Shift＋R 更新舊頁面，或從原桌面捷徑重新開啟。

## 立即使用

| 操作 | 按鈕／快捷鍵 |
|---|---|
| 在目前筆記插入研究連結 | 筆記工具列「連結研究項目」，或 Ctrl＋Shift＋L |
| 快速切換研究項目 | 頂列「切換」，或 Ctrl＋Shift＋K |
| 預覽連結內容 | 筆記下方「內文連結」區的「預覽」；搜尋視窗也有「預覽目前選項」 |
| 儲存目前筆記 | 「儲存筆記」，或 Ctrl＋S；只在筆記可編輯且沒有開啟對話框時攔截快捷鍵 |
| 全文搜尋／新增隨記 | 沿用 Ctrl＋K／Ctrl＋N |
| 搜尋結果鍵盤操作 | ↑ ↓ 移動選項，Enter 選取，Esc 取消；中文輸入法組字／選字時不觸發選取或全域快捷鍵 |

筆記下方有「快捷鍵與語法提示」，可展開查看 Markdown、導覽連結、APA 及固定版本摘錄的不同語法。常用快捷鍵同時顯示在按鈕旁；不需要先記住語法才能使用。

## 寫作連結

1. 開啟筆記，或在閱讀原文時開啟並排筆記。
2. 將游標放在要插入的位置；若先選取文字，插入會取代選取文字。
3. 開啟「連結研究項目」，輸入名稱、別名、作者或來源。
4. 核對種類、專案、作者／年份、來源位置與 ID。同名項目不會自動合併。
5. 選取後，連結加入目前草稿；游標留在連結後方。再儲存筆記才會寫入資料庫。

內文使用穩定 ID 標記，筆記下方「內文連結」區顯示可讀名稱及預覽／開啟按鈕。這仍是 Markdown 文字編輯器，並未更換成即時視覺編輯器。

導覽連結不會自動增加 APA 來源，也不會自動建立支持、反駁或其他正式關係。需要正式關係時，在預覽按「建立正式關係…」，會帶入目前筆記與目標，再由你確認類型、理由及專案。

## 預覽與快速切換

預覽按需向本機讀取目標目前版本，只提供短內容及必要資料，不附完整來源頁面或附件原始位元組。主內容最多 1,200 字，摘錄釋義與加註另有長度上限；開啟完整項目才載入全文。

預覽顯示項目種類、名稱、專案、版本，來源可顯示作者／年份；摘錄另顯示定位與核對狀態。AI 訊息保留角色，Gemini／NotebookLM 素材標示待核對。預覽不覆寫筆記中的引用快照。

從搜尋開啟預覽後可以返回搜尋；取消時恢復原筆記的選取範圍與游標。開啟完整項目之前，仍會提醒處理未儲存的草稿。目標已刪除或無法讀取時，不會先丟棄草稿；也不讓過期的預覽回覆覆蓋新的視窗。

快速切換與全文搜尋分開：快速切換只查名稱、別名、作者、來源等導覽資訊；全文搜尋繼續由原本的 Ctrl＋K 使用。搜尋結果最多顯示 40 筆，並顯示符合總數，可依種類及目前／全部專案縮小範圍。

## 跨專案、改名與刪除

搜尋預設沿用目前專案；需要跨專案時，明確切到「全部專案」。共用項目以同一 ID 出現，不複製來源或附件。

改名後連結仍指向同一 ID，載入最新資料時顯示新名稱。目標移除後，筆記文字保留原有標記，「內文連結」區標示目標已移除。右側新增「被筆記連結（導覽）」反向入口，沿用專案範圍；它與正式物件關係分開呈現。

## 匯出與備份

Markdown／HTML 報告會將導覽標記轉成可讀名稱、種類與 ID，標記失效目標。一般報告沒有提供離線應用程式跳轉，因此不輸出依賴 localhost 的假離線連結。

如果目標位於未納入輸出的其他專案，匯出保留其名稱與 ID，標示「內容未納入」，不自動帶出該筆記全文。導覽目標不會因此加入 APA 清單。

JSON 匯出保留原始標記與必要對照；完整 ZIP 備份保留可還原的原始內容。不新增資料庫格式、依賴或雲端服務，既有 APA 與固定版本摘錄機制保留。
